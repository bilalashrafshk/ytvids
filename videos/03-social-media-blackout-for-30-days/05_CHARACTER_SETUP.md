# Phase 05: Character Setup & Reference Blocks
## Episode 03: Social Media Blackout for 30 Days

> **Instructions**: Standalone visual direction deliverable. Establishes locked reference blocks for recurring characters before beat-by-beat generation begins.
>
> **LATEST ENGINE GATE AUDIT:**
> 1. **Standardized Filename Convention:** `000_[character-name]_reference.png` per Master Channel Bible (Phase 3).
> 2. **Single Static Pose Mandate:** Exactly ONE standalone 4K portrait prompt per character (3840×2160, 16:9).
> 3. **Mandatory Negative Prompt Clause:** Verbatim `"no turnaround, no multiple views, no character sheet, no front/side/back views in one image, single pose only"` included in every prompt to prevent multi-view generation.
> 4. **Standing Exclusions:** Excludes generic cartoon mascot styles, plastic 3D CGI looks, and low-effort round-head stick figures.
> 5. **Margery Rule (Zero Quota Obligation):** Margery is an in-world situational protagonist, never a generic news desk anchor. Since Draft B is driven by the ground-level warehouse operator and dock staff, Margery does not appear in this episode.
> 6. **Universal Quality Clause:** Verbatim `"follow best industry-standard guidelines and quality and visualisations"` included in 100% of prompts.
