# Phase 05: Character Setup & Reference Blocks — Episode 05

> **Track 3 (mechanism explainer). Honest scope note:** this episode has **no real people, no caricatures and no `[COMPOSITE]` tags**. The script names companies, not individuals, and the one quote (the AMD engineer) is shown as an on-screen message card, never as a face. The template asks for 2–4 characters; rather than invent a cast the script doesn't need, this file defines **three anonymous, recurring illustrated figures** that the beat sheet will otherwise redraw differently every time, plus one optional fourth that exists only if thumbnail C is chosen.
>
> **MANDATORY RULES (from the template):**
> 1. **Single static reference portrait only:** one standalone 3840×2160 (16:9) prompt per figure. No turnarounds, no character sheets.
> 2. **Illustrated vector style only:** no photoreal likenesses. Gesture-only, no lip-sync, no scripted dialogue.
> 3. **Every prompt carries verbatim:** `"follow best industry-standard guidelines and quality and visualisations"`.
>
> All figures are **invented and unnamed**. None resembles any real person, and none represents a real company's staff. They may not be given a name, a logo or a line of speech.
